# Luffy Gear 5 Codex Pet V2

This release upgrades the original “Luffy Gear 5” Codex pet to the v2 sprite
contract and adds a complete 16-direction look loop.

Highlights:

- Codex pet v2 manifest and 8×11 transparent atlas
- 16 clockwise look directions
- repaired failed and task-running animation semantics
- directly installable `luffy-gear-5-v2.codex-pet.zip`

Original pet by
[jordsshmords1](https://codex-pets.net/users/jordsshmords1), distributed through
[legeling/awesome-codex-pet](https://github.com/legeling/awesome-codex-pet/tree/main/pets/luffy-gear-5--jordsshmords1).
Many thanks to the original creator and upstream repository maintainers.
